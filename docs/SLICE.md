# 切片边界说明

本仓库是「注意力机制」研究框架的**公开脱敏切片**。这份文档说明：切了什么、为什么不切、以及**哪些数字属于生产系统而不属于本仓库**。

## 一、本仓库是什么

一套**独立可运行的最小实现**，用来公开方法与算法：

| 层 | 文件 | 作用 |
|---|---|---|
| 题材体系 | `src/ate/taxonomy.py` + `data/taxonomy.json` | 三级分类（行业 / 赛道 / 核心逻辑）+ 每个题材的核心逻辑 |
| 规则引擎 | `src/ate/rules.py` | 关键词规则 + 注意力权重 → 可解释打分与拒绝 |
| 注意力迭代 | `src/ate/attention.py` | 按分类误差回写关键词权重 |
| 评测 | `eval/evaluate.py` + `data/golden.jsonl` | Top-1 / Top-3 / 拒绝率 |

**代码是新写的最小实现，不是生产代码的拷贝** —— 生产系统的分类体系由真实数据源驱动、包含大量在生产中打磨出来的边界规则，那部分不适合整体公开。

## 二、生产系统里没有公开的部分

| 不公开 | 原因 |
|---|---|
| 完整概念集（生产侧规模为 420+ 条题材） | 属商业资产，且部分条目来自付费数据源的结构化结果 |
| 原始数据源接入层（12+ 数据源） | 含商业数据源凭据与抓取/接口适配逻辑 |
| 大模型语义解析层 | 提示词、模型选型与成本口径是生产配置 |
| 回测与信号层 | 样本外过滤规则的完整参数与样本 |
| 运营与调度逻辑 | 内部工程实现 |

## 三、⚠️ 数字口径（最重要的一条）

**本仓库的任何数字都不能与生产系统对外口径互相换算。**

| | 本仓库（公开切片） | 生产系统（对外口径） |
|---|---|---|
| 题材概念规模 | 31 条（`data/taxonomy.json` 全部） | 420+ 条 |
| 数据源 | 无（不接任何外部数据） | 12+ 个 |
| Top-1 准确率 | 见 README（**本仓库自带的 74 条自撰黄金样本**上的结果） | 对外口径另有数字，两者不是同一个量级的统计 |
| 样本外无效信号过滤率 | 负样本拒绝率 100%（**25 条自撰负样本**） | 对外口径另有数字 |

自撰黄金样本集**小、干净、由作者本人构造** —— 它能证明「机制是否正确、迭代是否有效、拒绝是否可靠」，
**不能**用来推断生产系统的泛化能力。任何把本仓库数字当成生产数字的说法都是错的。

## 四、样本集里的跨题材干扰样本

`data/golden.jsonl` 里有 9 条**刻意构造的跨题材干扰样本**（如「智算中心与光模块需求同步升温」）。
它们的用途是让注意力迭代有真梯度：基线会在这些样本上选错题材，迭代把权重挪向正确的那一侧。

这类样本是本仓库的核心测试资产 —— **没有它们，迭代就是空转**（基线 100% 正确时没有任何可学的梯度）。
